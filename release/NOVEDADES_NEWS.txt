GOWLINK STUDIO — BETA 1.4.1: UNIVERSAL DOWNLOAD ENGINE
ESPAÑOL

Beta 1.4.1 consolida el motor dual de descargas directas HTTP y multimedia
mediante yt-dlp, junto con la cola común, preferencias e historial persistentes.

NOVEDADES
- Cola FIFO en memoria y concurrencia configurable de una a tres descargas.
- Reintentos limitados para fallos transitorios y cancelación por trabajo.
- Archivos HTTP publicados desde temporales solo después de una descarga exitosa.
- Resolución de duplicados HTTP con omitir, copia numerada o sobrescritura elegida.
- Preferencias e historial terminal guardados en %LOCALAPPDATA%\GowLink.
- Logs e historial sin query ni fragmentos de URL.
- Color de acento aplicado de forma coherente y mejoras en el cierre de paneles.

ESTADO
Los proveedores externos siguen limitados a los extractores instalados y no
se garantiza compatibilidad con toda URL. La Beta 1.4.1 todavía no está
publicada. Consulte LEEME_README.txt y THIRD-PARTY-NOTICES.txt.

GOWLINK STUDIO — BETA 1.4.1: UNIVERSAL DOWNLOAD ENGINE
ENGLISH

Beta 1.4.1 consolidates direct HTTP and yt-dlp media downloads with a shared
queue, persistent preferences, and terminal download history.

WHAT'S NEW
- In-memory FIFO queue with configurable concurrency from one to three jobs.
- Bounded retries for transient failures and per-job cancellation.
- HTTP files are moved from temporary storage only after successful completion.
- Explicit HTTP duplicate actions: skip, numbered copy, or overwrite.
- Preferences and terminal history are stored under %LOCALAPPDATA%\GowLink.
- Query strings and fragments are removed from logged and persisted URLs.
- Consistent accent color and improved panel dismissal.

STATUS
External-provider support depends on the installed extractors; arbitrary URLs
are not guaranteed to work. Beta 1.4.1 has not yet been published. See
LEEME_README.txt and THIRD-PARTY-NOTICES.txt.

GOWLINK STUDIO — ベータ 1.4.1：ユニバーサルダウンロードエンジン
日本語

ベータ 1.4.1 では、HTTP 直接ダウンロードと yt-dlp メディア取得を統合し、
共通キュー、設定、および完了済み履歴を整備します。

新機能・改善点
- 1～3 件の同時実行数を設定できる、メモリ内 FIFO キュー。
- 一時的な障害に対する回数制限付き再試行と、ジョブ単位のキャンセル。
- HTTP ファイルは完了後に一時ファイルから移動されます。
- HTTP の重複時にスキップ、連番コピー、上書きを選択できます。
- 設定と完了済み履歴を %LOCALAPPDATA%\GowLink に保存します。
- URL のクエリとフラグメントはログと保存履歴から除去されます。
- アクセントカラーの統一とパネル操作を改善しました。

状態
外部プロバイダーの対応状況はインストールされた抽出ツールに依存し、
すべての URL が動作する保証はありません。ベータ 1.4.1 は未公開です。
LEEME_README.txt および THIRD-PARTY-NOTICES.txt もご確認ください。

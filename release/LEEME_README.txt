GOWLINK STUDIO — BETA 1.4.1
ESPAÑOL

Bienvenido a GowLink Studio Beta 1.4.1. Este paquete portable se distribuye
como una carpeta que puede extraerse en Windows x64.

USO PORTABLE
1. Extrae todo el contenido de GowLink-Desktop-win-B1.4.1.zip.
2. Conserva WASSLink.Desktop.exe y la carpeta tools juntos.
3. Ejecuta WASSLink.Desktop.exe. El nombre del ejecutable conserva el
   identificador técnico heredado; la aplicación se presenta como GowLink.
4. Usa Examinar para elegir la carpeta de destino. De forma predeterminada,
   las descargas se guardan en %USERPROFILE%\Downloads\GowLink.

REQUISITOS Y AVISOS
- El paquete incluye el runtime de .NET y las dependencias de escritorio; no
  requiere instalar .NET por separado. Está publicado para Windows x64.
- La carpeta tools contiene yt-dlp y FFmpeg; no la separes del ejecutable.
- Se requiere Internet para inspeccionar y descargar contenido.
- GowLink Studio es software beta, no un instalador; no crea accesos directos,
  asociaciones de archivos ni actualizaciones automáticas. Windows puede

- Respeta los derechos de autor, las licencias, los términos de servicio y la
  legislación aplicable. La capacidad técnica de descarga no concede permiso
